## B. 설문 설정

### B-1. Force Response **[필수]**

판단 문항 8개에 적용. 블록 헤더의 점 세 개 →
`Block Options → Question Behavior → Force Response` 로 일괄 적용.

### B-2. 민감 문항은 Request Response **[필수]**

인구통계·민감 문항까지 Force로 걸지 마세요. 응답 거부권은 연구윤리 사항이며
IRB 심의에서 지적받는 흔한 항목입니다.

### B-3. Timing 문항 추가 **[권장]**

Force Response는 **이미지 로딩 실패를 감지하지 못합니다.** 빈 화면을 보고
아무거나 찍어도 통과합니다. 각 시행 페이지에 Timing 문항(응답자에게 보이지 않음)을
넣어 First Click이 비정상적으로 짧은 응답을 사후에 걸러내세요.

### B-4. 공변량 문항 확정 **[권장]**

워드 초안에 `[확신도 · 금융 지식 수준 · 인구통계]` 로 비워둔 항목입니다.
최소한 **시행별 확신도**는 있는 편이 해석에 도움이 됩니다.

## C. 실험 설계

### C-1. 정답 배열이 교대 패턴 **[권장]**

현재 A→C→B→D 순서의 정답은 **비–낙–비–낙**입니다. 4시행이면 2~3번째에서
패턴을 알아채고, 4번째는 자극물이 아니라 패턴 추론으로 답하게 됩니다.
비–비–낙–낙 또는 비–낙–낙–비 처럼 교대가 아닌 배열을 권합니다.

> 단, 양 군에 동일 순서를 쓰는 원칙은 유지하세요.

### C-2. 자극물 A의 시기 회상 단서 **[권장]**

A(2021)에만 "코로나19"가 언급되어, 어조가 아닌 **시기 기억**에 근거한 응답이
나올 수 있습니다. 게다가 A가 **첫 시행**이라 여기서 생긴 해석 틀이 이후
3시행에 전이됩니다. 둘 중 하나:

- "코로나19" → "감염병 확산" 등으로 중화
- A를 3번째 시행으로 이동 (C-1과 함께 처리하면 한 번에 해결)

### C-3. 대시보드의 실질 조작 변인이 하나 **[선택]**

네 카드 모두 성명문 z가 음수(−0.12 ~ −0.18)이고 배지가 "정합"입니다.
종합 지수의 부호는 전적으로 기자회견 z가 결정하므로, 조작된 변인은 사실상
**기자회견 어조 하나**입니다.

- 순수 어조 강도를 보는 연구 → **현재 설계로 충분**
- 성명문–기자회견 **불일치(divergence)** 효과를 보려던 것이라면 → 현재 세트로는
  검정 불가. 불일치 조건 카드(예: 성명문 +0.6 / 기자회견 −0.5, 배지 "불일치") 필요
