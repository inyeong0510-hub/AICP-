# AICP — Qualtrics 설문 자극물 이미지

FOMC 커뮤니케이션 관련 설문 실험에 사용할 자극물 이미지 저장소입니다.
자극물은 두 종류이며, 모두 2000 × 1500 px (4:3) 입니다.

## A. 지수 카드 (`card_*`) — Fed 어조 지수 시각화

| 파일 | 종합 지수 | 방향 | 성명문 (z) | 기자회견 (z) | 배지 |
|---|---|---|---|---|---|
| `card_01` | **+0.47** | 낙관 | −0.18 | +1.12 | 정합 |
| `card_02` | **+0.30** | 낙관 | −0.15 | +0.75 | 정합 |
| `card_03` | **−0.32** | 비관 | −0.12 | −0.53 | 정합 |
| `card_04` | **−0.35** | 비관 | −0.18 | −0.53 | 정합 |

공통 요소: "의사록 반영 전 잠정치" 배지, 신뢰도 "보통", 하단 면책 문구.

> 참고: 네 카드 모두 성명문 z가 음수이고 종합 지수의 부호는 기자회견 z가 결정합니다.
> 즉 조작된 변인은 사실상 **기자회견 어조** 하나입니다.

## B. 뉴스 기사 카드 (`news_*`) — 금리 동결 보도

| 파일 | 헤드라인 | 금리 구간 | 국면 |
|---|---|---|---|
| `news_01` | 美연준 기준금리 동결…4.25~4.50% 유지 | 4.25–4.50% | 인하 3회 후 첫 동결 |
| `news_02` | 美연준 기준금리 5.25~5.5% 유지…4회 연속 동결 | 5.25–5.50% | 고금리 유지 (만장일치) |
| `news_03` | 美 연준, 6월 기준금리 동결 | 5.00–5.25% | 인상 사이클 중 첫 동결 |
| `news_04` | 미 연준, 제로금리 동결…완화적 통화 정책 유지 | 0.00–0.25% | 코로나 제로금리 |

공통 요소: 출처 `○○경제` (익명화), 3~4문장 리드, 하단 면책 문구.

> 참고: 네 기사 모두 **결정 내용은 "동결"로 동일**하고 금리 수준과 국면만 다릅니다.
> 헤드라인 길이가 1행(`news_03`)과 2행(`news_02`, `news_04`)으로 갈리므로,
> 같은 화면에서 비교 제시할 경우 높이 차이를 확인하세요.

## 포맷

동일 이미지를 두 가지 포맷으로 제공합니다.

- `images/png/` — PNG. Qualtrics 그래픽 라이브러리 업로드용 (호환성 최우선)
- `images/webp/` — WebP. 용량 약 1/5, `<img>` 직접 삽입용

## Qualtrics에서 사용하는 법

### 방법 1 — 그래픽 라이브러리 업로드 (권장)
`images/png/` 파일을 내려받아 **Library → Graphics Library** 에 업로드한 뒤
질문 편집기의 이미지 삽입 버튼으로 불러옵니다. 외부 호스팅에 의존하지 않아 가장 안정적입니다.

### 방법 2 — 외부 URL 직접 삽입
질문 편집기를 HTML 보기로 전환한 뒤 삽입합니다.

```html
<img src="RAW_URL/images/png/card_01.png" alt="FOMC 어조 지수 카드"
     style="width:100%;max-width:640px;height:auto;" />
```

`RAW_URL` 기본형:

```
https://raw.githubusercontent.com/inyeong0510-hub/AICP-/claude/epic-lovelace-gc056z/
```

> 주의: 방법 2는 저장소가 **public** 일 때만 동작합니다. 또한 GitHub raw는 CDN 캐시 지연이나
> 레이트 리밋이 걸릴 수 있어, 본 수집 단계에서는 방법 1을 사용하는 편이 안전합니다.
