# AICP — Qualtrics 설문 자극물 이미지

FOMC 회의를 소재로 한 **뉴스 기사** / **대시보드** 자극물 저장소입니다.
모든 이미지는 2000 × 1500 px (4:3).

## 명명 규칙

```
<자극물ID>_<연도>_<제시형식>.<확장자>
예) A_2021_기사.png , D_2025_대시보드.png
```

- 자극물 ID: `A`(2021) · `B`(2023) · `C`(2024) · `D`(2025)
- 제시형식: `기사`(언론군) · `대시보드`(대시보드군)
- 같은 ID의 기사/대시보드는 **동일한 FOMC 회의**를 다룬 쌍입니다.

## 자극물 일람

| ID | 연도 | 정답 | 기사 헤드라인 / 금리 | 대시보드 종합 지수 (성명문 z / 기자회견 z) |
|---|---|---|---|---|
| A | 2021 | **비관** | 제로금리 동결…완화적 통화 정책 유지 · 0.00~0.25% | **−0.35** (−0.18 / −0.53) |
| B | 2023 | **비관** | 美 연준, 6월 기준금리 동결 · 5.00~5.25% | **−0.32** (−0.12 / −0.53) |
| C | 2024 | **낙관** | 기준금리 5.25~5.5% 유지…4회 연속 동결 | **+0.30** (−0.15 / +0.75) |
| D | 2025 | **낙관** | 기준금리 동결…4.25~4.50% 유지 | **+0.47** (−0.18 / +1.12) |

기사 공통 요소: 출처 `○○경제`(익명화), 3~4문장 리드, 하단 면책 문구.
대시보드 공통 요소: "의사록 반영 전 잠정치" 배지, 신뢰도 "보통", 정합 배지, 하단 면책 문구.

## 제시 순서

두 군 모두 동일한 순서(A → C → B → D)로 제시하여 순서 효과를 통제합니다.

| 시행 | 언론군 | 대시보드군 | 정답 |
|---|---|---|---|
| 1 | `A_2021_기사` | `A_2021_대시보드` | 비관 |
| 2 | `C_2024_기사` | `C_2024_대시보드` | 낙관 |
| 3 | `B_2023_기사` | `B_2023_대시보드` | 비관 |
| 4 | `D_2025_기사` | `D_2025_대시보드` | 낙관 |

## 포맷

- `images/png/` — PNG. Qualtrics 그래픽 라이브러리 업로드용 (호환성 최우선)
- `images/webp/` — WebP. 용량 약 1/5, `<img>` 직접 삽입용

Qualtrics HTML 삽입용 스니펫 8종은 [`qualtrics/embed-snippets.md`](qualtrics/embed-snippets.md) 참고.

## Qualtrics에서 사용하는 법

### 방법 1 — 그래픽 라이브러리 업로드 (권장)
`images/png/` 파일을 내려받아 **Library → Graphics Library** 에 업로드한 뒤
질문 편집기의 이미지 삽입 버튼으로 불러옵니다.

### 방법 2 — 외부 URL 직접 삽입
파일명에 한글이 포함되어 있어 URL에서는 퍼센트 인코딩이 필요합니다.

- `기사` → `%EA%B8%B0%EC%82%AC`
- `대시보드` → `%EB%8C%80%EC%8B%9C%EB%B3%B4%EB%93%9C`

```html
<img src="https://raw.githubusercontent.com/inyeong0510-hub/AICP-/claude/epic-lovelace-gc056z/images/png/A_2021_%EA%B8%B0%EC%82%AC.png"
     alt="2021년 FOMC 뉴스 기사" style="width:100%;max-width:640px;height:auto;" />
```

> 주의: 방법 2는 저장소가 **public** 일 때만 동작합니다. GitHub raw는 CDN 캐시 지연이나
> 레이트 리밋이 걸릴 수 있어, 본 수집 단계에서는 방법 1을 사용하는 편이 안전합니다.
