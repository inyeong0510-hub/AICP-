# 분석 코드

| 파일 | 역할 |
|---|---|
| `prep.py` | Qualtrics CSV 2종 → `wide.csv` / `long.csv`. 채점, 파생 변수, 사전 등록 9절 제외 플래그 |
| `analyze.py` | H1–H4 검정. 전체 표본과 제외 적용 후를 각각 출력 |
| `supp.py` | 오답 방향, 강도 평정 대조, 대안 표본, 공변량, 자유응답 |

원자료 CSV는 IP·위치 열을 포함하므로 저장소에 넣지 않았다.
`prep.py` 상단 `SRC` 를 원자료 폴더로 지정하고 실행한다.

## 코딩

- 문항1: `1` = 평소보다 낙관적이었다, `2` = 평소보다 비관적이었다
- 시행 순서 A → C → B → D (사전 등록 4절)
- 정답: A(2021) 비관, C(2024) 낙관, B(2023) 비관, D(2025) 낙관
- 어조 정합 조정 지수: 낙관 시행 `(문항3 − 5)`, 비관 시행 `−(문항3 − 5)` 의 4시행 평균
